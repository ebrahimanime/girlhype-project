# Social Next.js App

A full-stack social media starter built with **Next.js (App Router, JavaScript)**, **MongoDB**, and **CSS Modules**.  
Features include authentication, a dashboard with sidebar and navbar, a post feed (create, like, comment, delete), profile page, and dark mode.

---

## 🚀 Features
- Landing page with logo + login form
- Register page → redirects to login after signup
- MongoDB + JWT authentication
- Protected routes with Next.js middleware
- Dashboard with:
  - Collapsible sidebar (Facebook-like)
  - Navbar (logo, search, theme toggle, profile, logout)
  - Feed (create, like/unlike, comment, delete own post)
- Profile page
- Dark mode toggle (persists with `localStorage`)
- Modular CSS styling
